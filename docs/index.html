02State

Two enums, both recovered from the engine's own reflection metadata. Only the first is stored on a live object.

EQuestStateQuestInstance +0x28  ·  int32

0Unavailable
1Availableregistered, not started
2InProgressbeing played
3Succeededterminal
4Failed

Found by scanning every quest in the registry for a field confined to {0..4}. It was the only candidate, and reads cleanly on all 194. A quest moves Available → InProgress → Succeeded, and Succeeded is terminal.

EQuestSectionStatedefined, never stored

0Unavailable
1Available
2Completednever stored
3Blocked

A real type with a real Completed value, and no home in memory. All 4016 section instances were scanned across their full 0xE0 bytes and no field holds it. A section's only live state is the fired byte on its trigger — and that trigger is destroyed when the quest ends.

03Burning Shores

The DLC hangs off the same registry, and its five main quests are now mapped: q31, q57, q183, q148, q67 — 101 declared objectives, every one decided on a falling edge.

q31 is the entry quest — Meet Sylens at Tilda's Mansion — and its section s2 clears the moment that objective completes. On the route that is the Sunwing cutscene skip, which is where the timer starts; the skip is where it happens, not why.

Three things are deliberately absent from the tree above. A quest's final objective never falls — measured on all five — so the quest's own +0x28 state change marks that instant instead. Some named beats produce no edge at all and cannot be split on. And the Epilogue is still unidentified: it does not start in the same pass as its predecessor's completion, unlike every other transition here.

A fixed base address for QuestSystem does exist in every build — it is simply not the same one twice, differing between game versions and between storefronts, so it is resolved by scanning for the byte pattern of the function that reads it. Every offset below it, and the 0x20 table stride, are properties of the engine's layout and hold across builds.

Slot and section numbers are stable across sessions, which is what makes them usable as identifiers at all.
